# Church reimbursement information

Static public information pages for church reimbursement applications.

- Hanover homepage: https://jiaxingzhang.github.io/hanover/
- Privacy notice: https://jiaxingzhang.github.io/hanover/privacy.html
- Terms: https://jiaxingzhang.github.io/hanover/terms.html

This repository contains only the informational HTML/CSS pages and the existing public form link. Application/deployment code, Google credentials, spreadsheet IDs, receipt files and reimbursement records belong in separate private resources and must never be copied here.

Google domain-ownership verification is performed separately by the church Google project owner. No placeholder or guessed verification token is included.
