Privacy notice

Effective date: November 8, 2026.

This notice describes the Hanover Reimbursements application used for Hanover Chapel receipt submissions.

Information collected

The submission form collects your name, the email address you provide, event name, store, receipt date, amount and uploaded receipt image or PDF. It also records the submission timestamp, processing status and a link to the stored receipt. Receipt files may contain other personal information visible in the document.

Use of information

The application uses this information to receive, store and organize reimbursement requests, send confirmations and treasurer reports, track processing status, and support safe operation and recovery of the application.

Storage and recipients

Google Apps Script runs the form and backend. Reimbursement records and receipt files are stored in Google Sheets and Google Drive controlled by the church account. The application attempts to email the submitted details and receipt attachment to the treasurer and the email address entered on the form. Treasurer reports may include links to stored receipts.

People authorized by the church to administer reimbursements or operate the application may access these records. Each church deployment uses its own configured account and storage resources; the application does not expose a public spreadsheet or receipt directory.

Google authorization and deployment automation

Google API data is used and shared in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

The church operator authorizes the release tools to identify the operator, access the configured Sheets and Drive resources, and manage Apps Script project code and deployments. The app also uses authorization to send reimbursement-related email. Submitters do not receive the operator's Google credentials.

GitHub hosts the deployment repository and runs authorized release automation. Deployment and recovery checks can process workbook contents in runner memory and create temporary native spreadsheet copies. Logs are designed to record checks, counts and hashes rather than receipt contents or spreadsheet cell values. Successful releases remove their temporary spreadsheet copies; failed or uncertain recovery retains a copy until the operator resolves it. The release process does not make separate backups of receipt files.

Retention and requests

The application does not implement an automatic retention period for reimbursement records or receipt files. Contact the treasurer to request access, correction or deletion, or to ask how church recordkeeping needs affect a request. Removing an original record does not recall email copies already delivered.

Other services and this information site

The application has no advertising or analytics integration of its own. This information site contains no submission form, scripts or cookies of its own. Its hosting provider may process technical request data under that provider's policies. Google and GitHub provide infrastructure subject to their own Google privacy policy and GitHub privacy statement.

Contact and updates

Send privacy questions and requests to hanoverchapelabc@gmail.com. This notice should be updated if the application's actual data handling changes.
